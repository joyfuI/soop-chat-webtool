# soop-chat-webtool

[soop-chat](https://github.com/joyfuI/soop-chat) 라이브러리를 활용한 웹앱 프로젝트

모노레포 연습 겸 Turborepo로 구성함

## 패키지 목록

* `api`(apps/api) - 공통 API 서버
* `gamepinball-helper`(apps/gamepinball-helper) [사이트](https://soop-gamepinball-helper.netlify.app/) - 예전에 일렉트론 앱으로 만든 "SOOP 종겜핀볼 도우미"를 웹으로 이식
* `@joyfui/api-client`(packages/api-client) - 공통 API 서버의 RPC 기능
* `@joyfui/typescript-config`(packages/typescript-config) - 공용 "tsconfig.json"
* `@joyfui/ui`(packages/ui) - 공용 UI 라이브러리
